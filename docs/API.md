# API

Base URL for local development: `http://localhost:4000/api`

In production, all generation, palette, and project routes require `Authorization: Bearer <Supabase access token>`. Obtain the token through Supabase Auth in the frontend; never send the Supabase service-role key to a client.

All error responses have the shape:

```json
{ "success": false, "error": "A human-readable explanation." }
```

## Health check

`GET /api/health`

```json
{ "status": "ok" }
```

## Generate a website

`POST /api/generate`

Request:

```json
{ "prompt": "Build a portfolio website for a frontend developer" }
```

The prompt must contain 3–2,000 characters after trimming. Successful AI-generated responses contain 4–8 sections, begin with a hero, end with a footer, and have unique section IDs:

```json
{
  "success": true,
  "website": {
    "title": "Developer Portfolio",
    "description": "A portfolio for independent frontend work.",
    "theme": {
      "primary": "#7c5cff",
      "background": "#ffffff",
      "text": "#171717"
    },
    "sections": [
      {
        "id": "hero-intro",
        "type": "hero",
        "heading": "Thoughtful interfaces, built for people.",
        "subheading": "Frontend developer and design-minded collaborator.",
        "body": "",
        "items": []
      }
    ]
  }
}
```

Allowed `type` values: `hero`, `about`, `features`, `services`, `products`, `categories`, `gallery`, `menu`, `faq`, `banner`, `team`, `stats`, `process`, `events`, `blog`, `location`, `schedule`, `logos`, `pricing`, `testimonials`, `contact`, and `footer`. The model chooses relevant section types and content for the prompt. Card-backed sections carry specific card content such as a name, description, optional price or metric, badge, and visual category used to select preview imagery. The server searches Wikimedia Commons using card names and returns matching thumbnail URLs and source-file attribution when available. Up to 8 cards are searched; if the search is unavailable or has no match, the frontend uses its curated Unsplash fallback. Wikimedia results include `imageUrl`, `imagePage`, `imageCredit`, and `imageLicense` on the card. E-commerce prompts must produce at least four named product cards. Color fields must be six-digit hexadecimal colors. The server returns `400` for invalid input, `401` for missing or invalid production authentication, `429` after 10 generation requests per minute per IP, `503` for missing configuration or temporary provider/storage failure, and `502` for invalid model output.

The live preview renders these sections using built-in editable templates; it does not run arbitrary React or JavaScript generated by the model.

## Generate a color palette

`POST /api/theme`

Request:

```json
{ "prompt": "Warm editorial design for a neighborhood wine bar" }
```

Prompt length must be 3–500 characters. Successful response:

```json
{
  "success": true,
  "theme": {
    "primary": "#a15f46",
    "background": "#f6f1e8",
    "text": "#292421"
  }
}
```

This endpoint shares the generation rate limit with `/api/generate`.

## Projects

All project endpoints require an authenticated Supabase user.

- `GET /api/projects` — list the current user's 30 most recently updated projects.
- `PUT /api/projects/:id` — create/update a project owned by the current user. The `id` must be a UUID. Body: `{ "prompt": "...", "website": <validated website schema>, "createdAt": "<ISO timestamp>" }`.
- `DELETE /api/projects/:id` — delete only a project owned by the current user.

Apply `supabase/migrations/20261031200000_projects.sql` (for example, with `npx supabase db push`) to provision the table, index, foreign key, and row-level-security policies.

## Operational notes

- The Gemini key is read only by the backend from `GEMINI_API_KEY`.
- The Supabase service-role key is backend-only (`SUPABASE_SERVICE_ROLE_KEY`). The frontend uses only the public publishable/anon key.
- Production startup fails fast if Gemini or Supabase server credentials are missing.
- In development only, absent Supabase server credentials permit unauthenticated generation and local-browser project history. This fallback is disabled in production.
- Project database queries always scope reads, updates, and deletes to the authenticated user ID; the database also has RLS policies for direct user-scoped access.
- Website and palette requests use a structured Gemini response schema, time out after 55 seconds per attempt, and retry transient provider 500/503/504, timeout, or network failures once. Repeated timeouts return an actionable slow-response message; check backend network access and Gemini model availability if they persist.
- Persistent Gemini overload returns HTTP `503` with a retry hint. Provider quota/rate limits are reported separately from app request validation; check the Google AI project quota and try again later.
- CORS allows only `FRONTEND_ORIGIN` (defaults to `http://localhost:5173`) and permits `GET`, `POST`, `PUT`, and `DELETE` requests with JSON and bearer-token headers.
- JSON request bodies are limited to 16 KB.
- Gemini-generated output is parsed and schema-validated before it leaves the API.
- Apply a shared rate-limit store and observability provider when horizontally scaling.
- When `NODE_ENV=production`, the API serves the built `frontend/dist` SPA and returns JSON for unknown `/api` routes.
